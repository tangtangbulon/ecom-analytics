# 业务指标计算口径文档 (V1.0)

**更新日期**：2023-10-25
**撰写人**：数据小白逆袭中

## 1. 指标名称
**毛利率** (Gross Margin Rate)

## 2. 计算公式
**毛利率 = (销售额 - 成本) / 销售额**

## 3. 数据清洗规则
1. 销售额为 0 或 空的订单不参与计算（返回结果默认为 0）。
2. 剔除重复订单（需在计算前进行去重操作，避免数据翻倍）。
3. 成本为空时，默认视为 0 成本参与计算。
4. 负数订单（如退货单、异常测试单）在分析时需根据业务需求过滤。

## 4. 业务分析备注（你的思考）
- 如果毛利率为负数，代表亏本销售。
- 运营最关心的数字：总体毛利率、Top 10 毛利爆款商品。
- 数据分析的尽头是业务，写完代码别忘了结合实际情况给老板讲数据背后的故事。

## 能力验收：GMV与净销售额
1. 业务理解：GMV是下单总额（包含退款、取消订单），净销售额是实际收到的钱（需扣减退款、折扣、无效订单）。
2. 差异公式：净销售额 = GMV - 退款金额 - 折扣优惠 - 无效订单。
3. AI协作规范：严禁让大模型直接输出业务数字。正确的流程是：让AI写代码(如Pandas/SQL) -> 本地跑出真实数字 -> 喂给AI进行文字归因分析。
